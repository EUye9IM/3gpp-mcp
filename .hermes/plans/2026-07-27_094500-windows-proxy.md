# Windows 系统代理支持 — 实施计划（v2）

> **Goal:** 为 3gpp-mcp 添加跨平台代理支持，Windows 下通过 `mattn/go-ieproxy` 读取系统代理设置。

**Architecture:** 在 `internal/core/` 新增 `proxy.go` 提供统一的 HTTP 客户端工厂；Config 新增代理字段；Downloader 和 CatalogStore 改用带代理的客户端。

---

### 选型

| 方案 | 评估 |
|------|------|
| 手写注册表读取 | ❌ 需处理 WinHTTP API、注册表路径、PAC 解析，代码量大 |
| **mattn/go-ieproxy** | ✅ 97 stars, mattn 维护，WinHTTP API + 注册表回退，CGO-free，一行接入 |

```go
// 使用方式
import "github.com/mattn/go-ieproxy"
http.DefaultTransport.(*http.Transport).Proxy = ieproxy.GetProxyFunc()
```

### Task 1: Config 添加代理字段

**File:** `internal/config/config.go`

```go
type Config struct {
    DataDir       string
    DynareportURL string
    HTTPUserAgent string
    ServerAddr    string
    Transport     string
    HTTPProxy     string // HTTP 代理地址 (可选，例如 "http://proxy:8080")
    HTTPSProxy    string // HTTPS 代理地址 (可选)
    NoProxy       string // 不走代理的地址 (逗号分隔，可选)

```

默认值均为空字符串（表示自动检测）。

### Task 2: 创建 HTTP 客户端工厂（条件编译）

**File:** `internal/core/proxy.go` — 公共接口

```go
package core

import (
    "net/http"
    "time"
)

// NewHTTPClient 创建带代理支持的 HTTP 客户端。
// 代理检测由平台特定实现完成 (proxy_windows.go / proxy_default.go)。
func NewHTTPClient(timeout time.Duration, httpProxy, httpsProxy, noProxy string) *http.Client {
    return &http.Client{
        Timeout: timeout,
        Transport: &http.Transport{
            Proxy: proxyFunc(httpProxy, httpsProxy, noProxy),
        },
    }
}
```

**File:** `internal/core/proxy_default.go` — Linux/macOS 实现

```go
//go:build !windows

package core

import (
    "net/http"
    "net/url"
)

func proxyFunc(httpProxy, httpsProxy, noProxy string) func(*http.Request) (*url.URL, error) {
    if httpsProxy != "" {
        if u, err := url.Parse(httpsProxy); err == nil {
            return http.ProxyURL(u)
        }
    }
    if httpProxy != "" {
        if u, err := url.Parse(httpProxy); err == nil {
            return http.ProxyURL(u)
        }
    }
    return http.ProxyFromEnvironment
}
```

**File:** `internal/core/proxy_windows.go` — Windows 实现

```go
//go:build windows

package core

import (
    "net/http"
    "net/url"

    "github.com/mattn/go-ieproxy"
)

func proxyFunc(httpProxy, httpsProxy, noProxy string) func(*http.Request) (*url.URL, error) {
    // 1. 显式配置优先
    if httpsProxy != "" {
        if u, err := url.Parse(httpsProxy); err == nil {
            return http.ProxyURL(u)
        }
    }
    if httpProxy != "" {
        if u, err := url.Parse(httpProxy); err == nil {
            return http.ProxyURL(u)
        }
    }
    // 2. Windows 系统代理 (ieproxy 支持 WinHTTP API + 注册表 + PAC)
    return ieproxy.GetProxyFunc()
}
```

这样 `go-ieproxy` 只在 Windows 构建时引入，Linux/macOS 零依赖开销。

### Task 3: 修改 Downloader

**File:** `internal/ingest/downloader.go`

将 `DownloaderConfig` 新增代理字段，`NewDownloader` 改用 `core.NewHTTPClient`：

```go
type DownloaderConfig struct {
    UserAgent  string
    Timeout    time.Duration
    HTTPProxy  string
    HTTPSProxy string
    NoProxy    string
}

func NewDownloader(cfg DownloaderConfig) *Downloader {
    if cfg.Timeout == 0 { cfg.Timeout = 30 * time.Second }
    return &Downloader{
        httpClient: core.NewHTTPClient(cfg.Timeout, cfg.HTTPProxy, cfg.HTTPSProxy, cfg.NoProxy),
        userAgent:  cfg.UserAgent,
        baseURL:    "https://www.3gpp.org/ftp/Specs",
    }
}
```
